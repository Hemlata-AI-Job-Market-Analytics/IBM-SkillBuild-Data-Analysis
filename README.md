## Project overview
This project analyzes the supplied `AI Job Market Dataset.csv` using Python data analytics and a baseline machine-learning model.

## Files
- `Hemlata_AI_Job_Market_Analysis.ipynb` — complete Jupyter Notebook/code.
- `requirements.txt` — Python dependencies.
- `Hemlata_AI_Job_Market_ProjectReport.docx` — project documentation.
- `README.md` — project overview and run instructions.
- `AI Job Market Dataset.csv` — input dataset supplied for this project.

## Dataset
**Dataset file:** `AI Job Market Dataset.csv`

A public dataset URL was not included in the supplied project materials, so no external link is invented here. Keep the CSV in the same folder as the notebook.

## Technologies
Python, Pandas, NumPy, Matplotlib, Scikit-learn, Jupyter Notebook.

## How to run
1. Install Python 3.10 or newer.
2. Put `AI Job Market Dataset.csv` beside the notebook.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Open the notebook:

```bash
jupyter notebook Hemlata_AI_Job_Market_Analysis.ipynb
```

5. Run all cells from top to bottom.

## Analysis performed
1. Dataset loading and structure inspection.
2. Missing-value and duplicate checks.
3. Descriptive statistics.
4. Salary distribution analysis.
5. Job-title and country analysis.
6. Work-arrangement analysis.
7. Experience-level salary comparison.
8. Skill prevalence and salary association analysis.
9. Hiring urgency and job-opening analysis.
10. Random Forest salary prediction with MAE and R² evaluation.

## Important interpretation note
The dataset is observational. Differences between groups are descriptive associations and do not prove causation. The salary model is a baseline academic exercise and should not be treated as a real-world compensation decision tool without independent validation.
